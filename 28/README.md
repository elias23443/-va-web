### O que aprendi?

- Aprendi que **links internos** conectam **páginas dentro do mesmo site ou projeto**.  
- São criados com a tag `<a>` e o atributo `href`, apontando para outro arquivo **no mesmo diretório ou em uma pasta diferente**.  
  - Exemplo: `<a href="contato.html">Contato</a>`  
  - Ou: `<a href="paginas/sobre.html">Sobre</a>`  
- Compreendi a diferença entre **links relativos e absolutos**:  
  - **Relativos:** apontam para arquivos **dentro do próprio projeto**.  
  - **Absolutos:** apontam para endereços **externos na web**.  
- Descobri que podemos **navegar entre pastas** usando `../` para voltar um nível no diretório.  
- O professor explicou que organizar bem as pastas facilita a criação de **menus de navegação internos**.  
- Aprendi que é possível criar **links de retorno**, conectando páginas entre si para **melhorar a navegação** do usuário.  
- Entendi que o uso correto de links internos é essencial para **estruturação, organização e acessibilidade** do site.
