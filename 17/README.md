## O tamanho das imagens importa para um site

[O tamanho das imagens importa para um site – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/8rkuukKA8a4?si=cG3F2kpBjxje9cHp)  

### O que aprendi?

- Aprendi que **o tamanho das imagens é muito importante** para o desempenho de um site.  
- Imagens **grandes demais** podem deixar a página lenta, prejudicando a experiência do usuário.  
- O tamanho ideal depende do **uso da imagem**:  
  - Fotos de fundo podem ser maiores, mas ainda precisam ser otimizadas.  
  - Ícones e logos devem ser pequenos para carregar rápido.  
- Descobri que é possível **reduzir o tamanho das imagens** sem perder qualidade significativa, usando ferramentas de compressão online ou softwares como Photoshop, TinyPNG e Squoosh.  
- Aprendi que imagens otimizadas ajudam a **melhorar o SEO** (posicionamento nos buscadores), já que sites rápidos são melhor avaliados.  
- O professor destacou que é importante **respeitar a proporção e a resolução** da imagem para que não fiquem distorcidas.  
- Compreendi que **equilibrar qualidade e tamanho** é essencial para criar sites profissionais, rápidos e agradáveis aos visitantes.
