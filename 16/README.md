## Formatos de imagens na Web

[Quais são os formatos para imagens na Web – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/xg-vHgLF0mI?si=DcdymAZ8_oNV3Coh)  

### O que aprendi?

- Aprendi que **existem diferentes formatos de imagens** para usar em sites, cada um com suas características.  
- Os principais formatos são:  
  - **JPEG/JPG** → bom para fotos e imagens com muitos detalhes; **compacta bem**, mas perde qualidade (lossy).  
  - **PNG** → suporta transparência e qualidade alta; ideal para ícones, logos e imagens que precisam de fundo transparente.  
  - **GIF** → suporta animações simples e poucas cores; usado para pequenos efeitos ou animações curtas.  
  - **SVG** → formato vetorial, escalável sem perder qualidade; perfeito para logos, ícones e gráficos.  
  - **WebP** → formato moderno que combina alta qualidade e compressão eficiente; cada vez mais usado na web.  
- Aprendi que **escolher o formato certo** influencia no **tempo de carregamento e na qualidade visual** do site.  
- Também é importante **otimizar as imagens**, reduzindo o tamanho do arquivo sem perder muita qualidade, para melhorar a performance do site.  
- Compreendi que imagens bem escolhidas e otimizadas ajudam a criar **sites rápidos, bonitos e profissionais**.
