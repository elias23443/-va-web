## Parágrafos e Quebras

[Parágrafos e Quebras – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/f6NTJdtEFOc?si=rg7o6miJ1qWsbKQL)

### O que aprendi?

- Aprendi a usar a tag **`<p>`** para criar **parágrafos**, separando blocos de texto de forma organizada.  
- Cada parágrafo é automaticamente exibido com **espaço antes e depois**, criando uma leitura mais clara.  
- Para inserir **quebras de linha** sem iniciar um novo parágrafo, usa-se a tag **`<br>`**, que não precisa de fechamento.  
- Compreendi a diferença entre **parágrafo (`<p>`)** e **quebra de linha (`<br>`)**:  
  - `<p>` cria blocos de texto separados.  
  - `<br>` força uma quebra de linha dentro do mesmo bloco.  
- É importante organizar o texto com parágrafos para melhorar **a leitura e a aparência da página**.  
- O professor mostrou que é possível adicionar **múltiplas quebras de linha** usando `<br>` várias vezes seguidas.  
- Aprendi que a combinação de parágrafos e quebras é essencial para **formatar textos e conteúdos longos** em páginas web.  
- Também vi que o HTML5 prioriza a **semântica**, ou seja, usar `<p>` para parágrafos torna o conteúdo **mais acessível para leitores e buscadores**.
