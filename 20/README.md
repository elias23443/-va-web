## Hierarquia de Títulos

[Hierarquia de Títulos – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/aiOEBhozEOg?si=OtDfm-g3z_oGCKkK)
) 

### O que aprendi?

- Aprendi que os **títulos em HTML** são representados pelas tags `<h1>` até `<h6>`.  
- `<h1>` é o **título principal** da página, enquanto `<h2>` a `<h6>` são subtítulos, com hierarquia decrescente.  
- Usar corretamente a hierarquia de títulos **organiza o conteúdo**, tornando a leitura mais clara para usuários e navegadores.  
- Descobri que títulos são importantes para **SEO**, pois mecanismos de busca entendem a estrutura da página pelos títulos.  
- O professor explicou que cada página deve ter **apenas um `<h1>`**, e os subtítulos devem seguir a ordem lógica (`<h2>`, `<h3>`…).  
- Compreendi que uma boa hierarquia facilita **acessibilidade**, ajudando leitores de tela a navegar pelo conteúdo.  
- Também aprendi que os títulos podem ser estilizados com **CSS**, mas a **hierarquia semântica deve ser mantida** para preservar significado.
