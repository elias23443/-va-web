## Citações e Códigos

[Citações e Códigos – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/8TgKFYkcO5Y?si=OF3ZzDxS6eIMLWQp)

### O que aprendi?

- Aprendi que o HTML possui (tags específicas para citações e trechos de código).  
- Para (citações):  
  - `<blockquote>` → usada para (citações longas), geralmente em bloco separado com recuo.  
  - `<q>` → usada para (citações curtas), normalmente dentro de um parágrafo.  
- Para (códigos):  
  - `<code>` → indica (trechos de código) ou comandos, usado dentro de texto normal.  
  - `<pre>` → preserva (quebra de linha e espaços), útil para blocos de código formatados.  
  - `<samp>` → usado para (saída de programas ou simulações).  
  - `<kbd>` → representa (entrada do teclado), útil em tutoriais ou instruções.  
- Compreendi que essas tags ajudam a (organizar conteúdos técnicos e literários), deixando a página mais clara.  
- O professor destacou que usar tags semânticas para citações e códigos melhora (acessibilidade e leitura por buscadores).  
- Aprendi que (combinar `<pre>` e `<code>`) é a prática correta para exibir blocos de código no site.
