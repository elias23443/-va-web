### O que aprendi?

- Aprendi que os **links em HTML** são criados com a tag `<a>`, chamada **âncora** (*anchor*).  
- O atributo principal é `href`, que define o **destino do link**, podendo ser:  
  - Uma **página externa** (ex.: `https://google.com`)  
  - Uma **página interna** do próprio site (ex.: `paginas/contato.html`)  
  - Um **link dentro da mesma página**, usando **âncoras** (`#idDoElemento`)  
- O atributo `target` define **onde o link será aberto**, sendo os principais:  
  - `_blank` → abre em uma **nova aba**.  
  - `_self` → abre na **mesma aba** (padrão).  
- Também é possível transformar **imagens, botões ou textos em links**, basta envolver com a tag `<a>`.  
- Descobri que podemos usar **links para e-mail** (`mailto:`) ou **telefone** (`tel:`), úteis em contatos e formulários.  
- O professor explicou que as **âncoras internas** ajudam na **navegação de páginas longas**, facilitando o acesso direto a seções específicas.  
- Aprendi que usar links corretamente melhora a **usabilidade, acessi**
