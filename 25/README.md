## Listas OL e UL

[Listas OL e UL – @Curso em Vídeo HTML5 e CSS3](https://youtu.be/JlE0pzESf5g?si=LCv4N-VF-EUFyRQQ)  

### O que aprendi?

- Aprendi que existem dois tipos principais de listas em HTML:  
  - Listas ordenadas (`<ol>`) → itens numerados automaticamente.  
  - Listas não ordenadas (`<ul>`) → itens com marcadores (bolinhas, quadrados, etc.).  
- Os itens da lista são criados com a tag `<li>` (list item).  
- Descobri que é possível anidar listas, colocando uma lista dentro de outra para representar subitens ou categorias.  
- Aprendi a alterar o tipo de marcador ou numeração usando o atributo `type`:  
  - Letras maiúsculas ou minúsculas, números ou números romanos.  
- Também é possível definir o número inicial de uma lista ordenada com o atributo (start).  
- As listas são muito úteis em menus, listas de tarefas, sumários e organização de conteúdo.  
- Compreendi que **usar listas corretamente melhora a estrutura e acessibilidade do site, além de facilitar a leitura do conteúdo.
